# Validation schemas

`sarif-schema-2.1.0.json` is copied unmodified from the official OASIS SARIF 2.1.0 Errata 01 schema:
<https://docs.oasis-open.org/sarif/sarif/v2.1.0/errata01/os/schemas/sarif-schema-2.1.0.json>.

The schema is distributed under the OASIS RF on RAND Terms Mode. The test adjusts only the in-memory draft identifier so Ajv 2020 can validate the schema; the checked-in source remains unchanged.
