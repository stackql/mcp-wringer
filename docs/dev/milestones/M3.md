# Milestone M3 report

This report records the generator, seeded run, safety, corpus, and minimization work completed for M3.

## What was built

- Added deterministic scenario generators for valid and mutated requests, JSON-RPC envelopes, raw JSON, sequences, read-only tool arguments, resources, prompts, and the ten stdio wire-fault cases. Built-ins use the shared `ExtensionRegistry`.
- Added a generic JSON Schema argument strategy using `fast-check`, with matching by tool name, argument path, and schema predicate.
- Added send-time safety checks, seed derivation, case and time budgets, request timeouts, restart policies, liveness and baseline probes, worker support, flaky confirmation, and a response-signature corpus.
- Added fresh-target minimization, `run` and `minimize` CLI commands, JSON run artifacts, and replay support for configured target environment variables. Inherited environment values are redacted from traces.
- Added five-seed fixture coverage for the quick schedule and expanded the fixture to exercise generated tool calls and wire faults.

## Choices worth noting

- `fast-check` 4.10.2 is a runtime dependency because the generic JSON Schema argument strategy is used by public fuzz runs, not only by tests.
- Quick uses 18 cases: eight generator families plus ten weighted wire-fault cases, so every built-in wire-fault variant is exercised in a default quick run.
- Reports contain environment variable names but not values. Values explicitly configured for a target and values from opt-in inherited environments are redacted from captured traces.
