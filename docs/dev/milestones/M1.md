## Not verified and why

- HTTP replay is not part of M1; the scenario model reserves tagged HTTP wire descriptors for M4.

## Choices worth noting

- `cross-spawn` 7.0.6 is the only runtime dependency. It safely handles Windows command shims without constructing an unescaped shell command. The target environment remains minimal unless explicitly configured.
- The modern profile adds `clientCapabilities`, `clientInfo`, and `protocolVersion` metadata to each request; it emits no initialization handshake. The legacy profile emits `initialize`, awaits its response, then sends `notifications/initialized`.
- The conformance repository's expected-failure handling was reviewed; its GitHub license metadata is `NOASSERTION`, so no code was reused.
- The official JSON-RPC 2.0 document and pinned MCP lifecycle, transport, versioning, and schema sources were consulted. No protocol behavior was inferred solely from recollection.
