# Milestone M0 report

## What was built

M0 scaffold and guardrails are in place:

- TypeScript package scaffold for `@stackql/mcp-wringer` with strict compiler settings, ESLint, Prettier, Vitest, build scripts, and the scripts defined in `AGENTS.md`.
- Initial source layout with CLI, plugin surface placeholder, and Action entrypoint scaffold.
- CI workflow for Linux, macOS, and Windows on Node 22.x and 24.x.
- Governance and community files: `SECURITY.md`, `CONTRIBUTING.md`, `CODEOWNERS`, `.github/dependabot.yml`, and `CLAUDE.md`.
- Spec sync script, vendored schemas for revisions `2025-11-25` and `2026-07-28`, and `spec/SOURCE.json`.
- README stub describing scope and authorised-use requirement.

## Not verified and why

- CI was not run on Linux, macOS, Windows, or the full Node matrix. The cross-platform acceptance gate remains pending; the work order requires it before M0 is complete or later milestones begin.

## Choices worth noting

- Selected TypeScript, `tsup`, Vitest, ESLint flat config, and Prettier. Dependency versions were checked against npm on 2026-10-08.
- `package.json` sets Node `>=22.13.0`, with CI on Node 22.x and 24.x. The 22.13 floor is required by the selected ESLint major.
- Spec source pinned to `modelcontextprotocol/modelcontextprotocol` commit `0a11bf68c7ec4473526ec15589f592afcd12d1e8`.
- `spec:sync` omits run-time timestamps so `spec/SOURCE.json` remains reproducible.
- Workflow actions are pinned to full commit SHAs for `actions/checkout` v7.0.1 and `actions/setup-node` v7.1.0.
- The `esbuild` override selects 0.28.2 to clear an advisory affecting the versions selected by `tsup` and Vitest. `npm audit` reports no remaining vulnerabilities.

## Deviations from work order

- CI exists but has not been executed, so the M0 acceptance gate is not complete.
