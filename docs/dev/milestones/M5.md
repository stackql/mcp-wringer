# M5: Configuration, plugins, reporters

Added schema-derived configuration types, JSON Schema publication, profile/file/environment/CLI precedence, origin reporting and validation with unknown-key suggestions. Wired generator weights, argument strategy options, oracle selection and severity overrides, reporter selection and new/stale finding baselines through the CLI and run loop. Added the versioned plugin surface and a consumer-tested example plugin, SARIF/JUnit/Markdown reporters, and user documentation.

The baseline format is a JSON object with `formatVersion: 1` and a unique `findingIds` array. A baseline mismatch fails the CLI independently of `failOn`. Empty generator and argument-strategy selections use all built-ins (or all loaded strategies); an empty oracle selection enables all registered oracles. Reporter options are passed to plugin reporters and custom outputs use the reporter's declared file extension.

The SARIF test schema is the official OASIS Errata 01 schema, checked in with its source attribution. Ajv 2020 receives an in-memory draft identifier adjustment because the published schema declares draft 4; the checked-in schema is unmodified.

No runtime dependencies were added. The API report and example consumer test are separate CI steps after the package build. No releases or external repository changes were made.
