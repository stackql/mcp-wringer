The Action runtime is Node 24. Its bundle embeds runtime dependencies and is emitted as `.cjs` so Node interprets it as CommonJS despite the package-level `"type": "module"`. Source maps are omitted because their contents differed between operating systems and broke the cross-platform bundle-drift gate. Hosted CI first exposed an invalid checkout action SHA and then the Action's external runtime imports; both were corrected and the follow-up CI and Action self-test runs passed. The release job installs npm 11.5.1 before the trusted-publishing version check and publish. This machine has npm 11.0.0, so that release-only version check was not verified against an installed npm 11.5.1; the version gate logic was checked with a simulated user agent. The publishing workflow itself was not run.

No runtime dependencies were added. The untracked maintainer `AGENTS.md` was left untouched. No release, tag, publish, or Marketplace listing was made.
