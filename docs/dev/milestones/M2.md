## Choices worth noting

- Ajv is a runtime dependency because schema-response oracles validate messages using the vendored revision schemas. `@modelcontextprotocol/server-everything` is a dev dependency used only by the clean-run regression test.
- Output-size and error-detail observations are informational/diagnostic where the specifications do not define a violation.
- The modern fixture's wrong-response-ID defect leaves `server/discover` intact so the test harness can establish readiness before exercising the defect on the case request.
