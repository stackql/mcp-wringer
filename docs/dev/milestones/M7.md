# M7: Coverage feedback experiment

Added an experimental coverage-provider registry, public plugin registration and built-in providers for Node V8 and Go coverage. Coverage feedback is disabled by default. When enabled, it gathers coverage after generator batches and influences later generator selection; it is restricted to spawned stdio targets with one worker and `restartPolicy: "per-case"`.

| Acceptance check | Verification | Result |
|---|---|---|
| Coverage provider extension point, opt-in by default | `npm run check`; `npm run check:plugin-api`; `npm run docs:config:check` | Passed; plugin API declaration report and generated config documentation updated |
| Node V8 provider and coverage-guided generator selection | `npx vitest run test/coverage-feedback/providers.test.ts` | Passed; Node fixture emitted V8 range data, and batch schedule plus feature counts were recorded |
| Go coverage provider with an instrumented fixture | `npx vitest run test/coverage-feedback/providers.test.ts` | Passed on this host; Go fixture compiled with `go build -cover`, emitted data, and detected the configured error-code defect |
| Compare case-to-first-detection and total run time | `npm run evaluate:coverage-feedback` | Passed; three repetitions for four Node fixture defects and one Go fixture defect; detailed measurements and limitations are in [coverage-feedback.md](../design/coverage-feedback.md) |
| Measurement-based keep/change/drop recommendation | `docs/dev/design/coverage-feedback.md` | Recorded a change recommendation: keep experimental and off by default; no earlier detection in this short matrix, appreciable Go overhead, and no coverage output after an abrupt target failure |
| Safety and target scope remain unchanged | `npm run check`; coverage validation tests | Passed; coverage mode rejects HTTP, multiple workers, incompatible restart policies, and conflicting caller-supplied provider environment variables |
| Bundle and package integration | `npm run check:action`; `npm run test:action`; `npm run check:package` | Passed; Action bundle rebuilt to include the shared coverage configuration and runner code |
| Hosted CI and Action self-test | GitHub Actions runs `37834735164` and `37834735139` for commit `e49fb0e` | Passed; CI on Linux, macOS, and Windows with Node 22 and 24; Action self-test on Linux, macOS, and Windows |

No runtime dependencies were added. Coverage batch assignment and feature counts are reported in run metadata. If a target fails before writing coverage, the run preserves its findings and emits a diagnostic; it does not fabricate a coverage result. The evaluation is intentionally narrow: one revision, local Node and Go fixtures, four Node defects, one Go defect, three repeats of one seed and one batch size. No production or attached HTTP target was used.
